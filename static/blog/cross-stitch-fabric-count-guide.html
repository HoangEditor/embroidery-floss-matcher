What Does "14-Count" Mean?

Fabric count = stitches per inch. 14-count Aida has 14 squares per inch. Higher count = smaller stitches = more detailed design in the same space.

Fabric Count Comparison

CountStitches/inchRecommended ThreadBest For
11-count113-4 strandsKids, beginners, bold designs
14-count142-3 strandsStandard, most patterns
16-count162 strandsMore detail, medium projects
18-count181-2 strandsFine detail, HAED-style
28-count linen28 (over 2)2 strandsAdvanced, samplers, heirloom

How Fabric Count Affects Thread Color Choice

Thread looks lighter on higher-count fabric (less thread per area). A color that's perfect on 14-count may look washed out on 18-count. When in doubt, go one shade darker for high-count fabric. Use our floss matcher to find darker alternatives in the same DMC color family.
