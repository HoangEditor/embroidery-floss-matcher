Why DMC hex codes matter

If you're creating cross-stitch patterns digitally, you need accurate color representation. DMC doesn't publish official RGB values — the hex codes on this site come from community color-measurement projects that sampled actual DMC thread under calibrated lighting. They're as close as you'll get without owning a spectrophotometer.
