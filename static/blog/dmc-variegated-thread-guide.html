DMC Color Variations is variegated 6-strand cotton floss — each skein transitions through multiple shades of the same color family. Here's how to use it effectively.

How Variegated Thread Works

Each skein is dyed in sections — the color changes every 2-4 inches. As you stitch, the colors naturally blend, creating a watercolor-like effect. No two skeins are identical, which is the point — it adds handmade warmth.

When to Use Color Variations

  • Landscapes: Skies, water, fields — the color transitions look organic
  • Florals: Petals and leaves gain depth without changing threads
  • Background fills: Large areas that would look flat with solid color come alive
  • NOT for: Small areas (less than 1 inch) — the color change won't be visible. Text or fine detail — variegation makes it hard to read.

Stitching Technique

For cross-stitch: complete each X individually (not ////// then \\\). This keeps color transitions tight. For embroidery: use shorter stitches in areas where you want the color to change faster.

Color Families Available

DMC makes 60+ Color Variations shades, each based on a solid DMC color family. Example: 4025 (variegated reds) transitions through shades similar to DMC 321-666-304.
